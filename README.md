Wickfall is an original browser game. Gather every ember in each wave before the shadow tide reaches the shore: dodge the violet wisps, and dash (Space, or click toward the cursor) to become untouchable for a moment. Five waves to win, three lives, with a title screen, HUD, wave pauses, and win and loss screens with restart. It is plain static files under `game/` with no build step and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The game can also be opened from `game/index.html` through any static server.
